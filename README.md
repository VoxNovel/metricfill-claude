# Metricfill plugins for Claude

This repository publishes the [Metricfill](https://metricfill.com) plugin for
Claude: the Metricfill connector plus a skill that teaches Claude when and how
to use it.

- Plugin: [`plugins/metricfill`](plugins/metricfill)
- Help: [metricfill.com/claude](https://metricfill.com/claude)

Install in Claude Code:

```bash
claude plugin marketplace add VoxNovel/metricfill-claude
claude plugin install metricfill@metricfill
```
